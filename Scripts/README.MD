# Scripts used in analysis of CA Dengue project 

1. *Temperature_R0_Functions.R*   Includes functions for temp-dependent trait value estimations, calculating overall R0, and creating temperature rasters
2. *VectorDataProcessing.R*   Includes functions for processing CalSurv data 
3. *ClimateDataComparison.R*    Includes code for comparing climate data sources to use in analysis (namely CA BCM and CHELSA)
4. *R0_Estimation_CA_BCM4.5.R*   Contains code for estimating R0 based on CA BSM data input
5. *R0andVector_Overlap.R*    Contains code for identify areas of overlap in R0 and vector presence
6. *CADengue_DescriptiveStats.R*    Contains code for calculating and plotting descriptive stats include spatial and temporal trends in cases, vector presence, and climate suitability
