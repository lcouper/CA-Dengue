# R Scripts used in analysis

1. <ins>Temperature_R0_Functions_Public.R </ins>   This script includes functions for temperature-dependent trait value estimations, calculating overall R0, and creating temperature rasters.
2. <ins>R0_Estimation_CA_BCM4.5_Public </ins>   This script estimates R0(T) across California, using temperature data from CA BCM 
5. <ins>CAdengue_RiskLayers_Overlap_PopulationAtRisk_Public </ins>    This script outputs rasters identifying the regions 'at risk' for dengue, based on being above the ecological or eco-epidemiological 'threshold' for local transmission. These rasters are then procssed in qGIS, along with human population density estimates from CA-POP ([Depsky et al. 2022](https://journals.plos.org/plosone/article?id=10.1371/journal.pone.0270746).)
6. <ins>CADengue_DescriptiveStats.R </ins>    Contains code for calculating and plotting descriptive stats include spatial and temporal trends in cases, vector presence, and climate suitability
