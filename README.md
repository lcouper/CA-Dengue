# California Dengue 

This repository contains the scripts and datasets (mock versions for restricted use data) accompanying the manuscript "Climate warming and urbanization may expand dengue transmission risk in California"_ by Lisa Couper, TJ Sipin, Sam Sambado, Zoe Rennie, Kyle Shanebeck, Kelsey Lyberger, Phil Collender, Van Ngo, Justin Remais, and Andy MacDonald.    

The manuscript describes investigation of current and future dengue transmission risk in California and is available as a pre-print here [link coming soon].
