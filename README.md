# California Dengue 

This repo contains scripts and analytical details accompanying the manuscript _"Climate warming and urbanization may expand dengue transmission risk in California"_ by Lisa Couper, TJ Sipin, Sam Sambado, Zoe Rennie, Kyle Shanebeck, Kelsey Lyberger, Phil Collender, Van Ngo, Justin Remais, and Andy MacDonald.    

The manuscript describes investigation of current and future dengue transmission risk in California and is available as a pre-print here [link coming soon].
