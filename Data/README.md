# Location of data files and soucres used in the analysis

1. Raw climate data were obtained from the USGS and is publicly available [here](https://ca.water.usgs.gov/projects/reg_hydro/basin-characterization-model.html)
2. Raw land cover data were obtained from the USGS and is publicly available [here](https://www.mrlc.gov/data?cookiesession8341=3067D6B54BF8DCB51141A25C4A888730)
3. County-level dengue case data for California were generated by the California Department Public Health and is publicly available [here](https://www.cdph.ca.gov/Programs/CID/DCDC/Pages/DengueInfectionsUpdate.aspx)
4. Downstream data products used in our analysis are available [here](https://github.com/lcouper/CA-Dengue/releases/tag/denge_project_release)
